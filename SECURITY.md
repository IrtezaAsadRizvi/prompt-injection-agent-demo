# Security

The payloads in this repository are inert demos for teaching. All secrets are fake (for example `npm_FAKE_123`), the attacker server binds to 127.0.0.1 only, and no code makes real network calls unless you explicitly opt into real model mode with `MODEL=real` and your own API key.

Do not point a real, tool-enabled AI agent at this repository's files, issues or pull requests. The fixtures are written to manipulate agents, and they work.

If you find a way this repo could cause real harm (for example a payload that escapes the sandbox described above), please open a private security advisory on GitHub rather than a public issue.
